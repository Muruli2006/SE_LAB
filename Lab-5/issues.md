# Lab 5 — Static Analysis & Code Audit Findings

| Unsafe Shell Command Execution (Command Injection) | Security (High) | Bandit (`B605:start_process_with_a_shell`, CWE-78) | Line 43 | `logConflicts` used `os.system("cat " + file)` with string concatenation, introducing command injection vulnerabilities and crashing on Windows where `cat` is not native. | Removed `os.system` and replaced with native Python file reading using `with open(file, "r", encoding="utf-8")`. | Bandit report confirms 0 high-severity issues (`bandit_after.txt`); unit test `test_conflict_logging` passed. |
| Overlapping Time-Slot Room Conflicts Ignored | Logic Bug / Data Integrity | Manual Code Audit / Unit Testing | Lines 13–15 | The original scheduler only checked exact string equality (`slot == time_slot`). Overlapping intervals on the same room (e.g., `09-11` and `10-12`) were not detected, and the function booked the room despite the conflict. | Refactored time validation into `_parse_slot` and implemented interval overlap detection `max(start_hour, res_start) < min(end_hour, res_end)`. | Non-Atomic Equipment Allocation & Negative Stock | Logic Bug / Inventory Integrity | Manual Code Audit / Unit Testing | Lines 16–17 | Equipment was decremented in a loop without verifying if all requested equipment existed or if inventory was sufficient. | Mutable Default Argument | Bug / Reliability | Pylint (`W0102:dangerous-default-value`) | Line 11 | `schedule_room` defined `equipment_list=[]` as default parameter.
